
# AI Food Supply Chain Spoilage Predictor

An ML-powered cold-chain decision support dashboard
for estimating the remaining shelf life of perishable
food shipments.

## Objectives

- Estimate remaining shelf life using regression.
- Analyze environmental and logistical conditions.
- Simulate temperature and transit-time changes.
- Prioritize shipments based on estimated urgency.
- Evaluate predictions using MAE and RMSE.

## Technology Stack

- Python
- Pandas and NumPy
- Scikit-learn
- Plotly
- Streamlit

## Project Status

Phase 1: Environment setup and dataset investigation.

## Data and Limitations

Public datasets and simulated transportation records
will be documented separately. Simulated targets will
not be presented as experimentally validated results.
